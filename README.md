# Mariya Media Ltd (React + Vite)

    npm install
    npm run dev      # local dev server
    npm run build    # production build in dist/

- Content: `src/data.js`. Set `src` on any achievement or crew item to use a real photo (put images in `public/` and use `/name.jpg`).
- Styles: `src/index.css`. Icons: `src/components/Sprite.jsx` and `<Icon name="..." />`.
